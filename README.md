# PROYECTO-4-ANALISIS-DE-INSTACART

## 📌 Descripción del proyecto

Este proyecto consiste en un análisis exploratorio y preprocesamiento de datos de Instacart, una plataforma de entrega de comestibles similar a Uber Eats o DoorDash.

El objetivo principal fue limpiar, transformar y analizar diferentes tablas relacionadas con pedidos, productos y comportamiento de compra de usuarios para encontrar patrones de consumo y hábitos de compra.

Durante el proyecto se trabajó con múltiples datasets relacionados entre sí, aplicando técnicas de análisis de datos utilizando Python y Pandas.

---

# 🎯 Objetivos del proyecto

- Realizar limpieza y preprocesamiento de datos
- Detectar y eliminar valores duplicados
- Identificar y tratar valores ausentes
- Validar tipos de datos
- Analizar patrones de compra de usuarios
- Visualizar resultados mediante gráficas
- Obtener insights sobre comportamiento de clientes

---

# 🛠 Tecnologías utilizadas

- Python 3
- Pandas
- Matplotlib
- Jupyter Notebook

# 📁 Datasets utilizados

Los siguientes archivos CSV fueron utilizados durante el proyecto:

- `instacart_orders.csv`
- `products.csv`

- `departments.csv`
